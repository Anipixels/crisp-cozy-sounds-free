# Crisp Cozy Sounds Free

20 free soft, cozy UI sounds (wood taps, bubble pops, coins, page turns, planting...) and a small autoload: CrispCozySfx.play("click"), with volume, bus and polyphony.

Free sampler of Crisp Cozy: https://anipixels.itch.io/crisp-cozy
Demo scene: `res://addons/crisp_cozy_free/demo/cozy_sounds_demo.tscn`
Documentation: https://github.com/Anipixels/crisp-cozy-sounds-free
